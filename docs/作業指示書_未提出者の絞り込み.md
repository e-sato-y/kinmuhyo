## 1. 目的

月末に管理者（総務）が「まだ提出していない人は誰か」をすぐ見つけて声をかけられるようにする。
今の管理者画面は全社員が氏名順に並ぶだけなので、人数が増えると未提出の人を探しにくい。

## 3. やってほしいこと

### (1) 状態で絞り込む
一覧の表の上（「表示を更新」ボタンの並び）に、絞り込みの選択欄を追加する。

| 選択肢 | 表示する人 |
|---|---|
| すべて（初期値） | 全員 |
| 未提出のみ | 状態が「未作成」または「作成中」の人 |
| 未作成のみ | 勤務表がない人 |
| 作成中のみ | `draft` の人 |
| 提出済のみ | `submitted` の人 |

### (2) 並べ替える
並べ替えの選択欄を追加する。

| 選択肢 | 並び順 |
|---|---|
| 氏名順（初期値） | 今と同じ |
| 状態順 | 未作成 → 作成中 → 提出済（同じ状態の中は氏名順） |
| 最終更新が古い順 | 勤務表のない人を先頭に、`updated_at` が古い順 |

### (3) 件数の表示
今のメッセージ「社員 ◯人のうち、提出済 ◯人」に、**未提出の人数**も加える。
例：「2026年11月：社員 12人のうち、提出済 9人・未提出 3人」
絞り込み中は、表の上か下に「◯人を表示中」と出す。

### (4) 「要確認」の人も目立たせる（できれば）
実働時間の欄に「要確認 ◯件」が出ている人（赤字の日がある人）は、行の背景を薄い黄色にする。

## 4. 守ってほしいこと（重要）

1. **ボタンの番号のずれに注意**
   今の「表示」「Excel」「差し戻し」ボタンは `data-index`（`adminList` の何番目か）で社員を特定している。
   絞り込み・並べ替えで表示順が変わっても、**押したボタンと別の人の勤務表が開いたり差し戻されたりしないこと**。
   → `adminList` 自体は並べ替えず、表示用に別の配列を作る、または `data-id="社員のid"` で特定する方法に変えるなど。
2. **データベースは読み直さない**
   絞り込み・並べ替えを変えたときは、読み込み済みの `adminList` を使って表を作り直すだけにする（`loadAdmin()` は呼ばない）。
3. **「全員分をExcel出力」は今まで通り**
   絞り込み中でも、勤務表のある全員分を出力する（絞り込みの影響を受けない）。
4. 対象年月を変えたり「表示を更新」を押したりしても、選んだ絞り込み・並べ替えはそのまま残す。
5. 氏名などを画面に出すときは今と同じく `escapeHtml()` を通す。
6. データベース（`supabase/schema.sql`）・`config.js`・`vendor/` は変更しない。
7. コメントは今のコードに合わせて、日本語で初心者にもわかるように書く。

## 5. 確認してほしいこと

パソコンで試すときは、`kinmuhyo` フォルダで次を実行して `http://localhost:8000` を開く。

```bash
python -m http.server 8000
```

管理者でログインし（管理者アカウントは佐藤に確認）、次をチェックする。

- [ ] 「すべて」で今と同じ一覧が出る
- [ ] 各絞り込みで正しい人だけが出る（未作成・作成中・提出済の人が最低1人ずついる月で試す）
- [ ] 各並べ替えで正しい順に並ぶ
- [ ] 絞り込み・並べ替えをした状態で「表示」「Excel」「差し戻し」を押して、**その行の人**のものが開く／出力される／差し戻される
- [ ] 「全員分をExcel出力」が絞り込みに関係なく全員分になる
- [ ] 年月を変えても絞り込み・並べ替えの選択が残る
- [ ] スマホの幅（ブラウザの幅を狭くする）でも選択欄が崩れない
- [ ] ブラウザのコンソールにエラーが出ていない
