# 勤務表サイトのフロントエンド制作のお願い

あなたには、社内向けの「月間勤務表サイト」のフロントエンド（画面）を作ってもらいます。
バックエンド（ログインとデータ保存）は **Supabase** で構築済みで、データベースの形とアクセスの決まりは変えられません。
以下の構想・仕様に沿って、見た目と使いやすさを高めた画面を作ってください。

---

## 1. どういうサイトか

- 小さな会社（社員十数名〜数十名）の **月間勤務表を作成・提出するための社内サイト**。
- 社員は毎月、自分の勤務表（1日ごとの出勤・退勤・休憩・勤務区分・備考）を入力し、月末に「提出」する。
- 管理者（総務担当など）は、全社員の提出状況を一覧で確認し、Excel に出力して給与計算などに使う。
- これまでは1人用の HTML ツールで Excel を作っていた。それを全社員がブラウザから使えるようにしたもの。

### 方向性
- **事務作業を早く・迷わず終わらせる道具**。派手さより、見やすさ・入力のしやすさ・間違えにくさを優先する。
- 利用者はパソコンが得意でない人も含む。**専門用語を使わず、やさしい日本語**で案内する（例：「保存済み 14:32」「赤字の日を直してから提出してください」）。
- パソコンで使うのが中心だが、**スマホでも入力できる**こと（表は横スクロール可）。
- 落ち着いた業務アプリの雰囲気。基調色は紺（#2F5D8A）、Excel 出力ボタンは緑（#217346）。土曜は薄い青、日曜・祝日は薄い赤で行を色分けする。

---

## 2. 利用者と権限

| 利用者 | できること |
|---|---|
| 一般社員 | 自分の勤務表だけを作成・編集・途中保存・提出・Excel出力。氏名を変更できる |
| 管理者 | 上記に加えて、全社員の勤務表の一覧・閲覧（読み取り専用）・Excel出力（1人ずつ／全員分）・差し戻し |

- 新規登録画面は **作らない**。社員は管理者が Supabase から招待し、招待メールのリンクからパスワードを設定する。
- 権限の制御はデータベース側（RLS）で行われているので、画面は「見せる・隠す」だけでよい。

---

## 3. 画面構成

### (1) ログイン画面
- メールアドレス・パスワード・「ログイン」ボタン
- 「パスワードを忘れた場合」リンク → 入力済みのメールアドレスに再設定メールを送る

### (2) パスワード設定画面
- 招待メール・再設定メールのリンクから開いたときに表示（URL の `#` 以降に `type=invite` または `type=recovery`、もしくは Supabase の `PASSWORD_RECOVERY` イベント）
- 新しいパスワード（8文字以上）を2回入力して設定 → そのまま勤務表画面へ
- リンクの期限切れなど（URL に `error_description`）は、ログイン画面でわかりやすく案内する

### (3) 勤務表画面（ログイン後のメイン画面）
- 上部：タブ「自分の勤務表」「管理者」（管理者だけ表示）、ログイン中のメールアドレス、ログアウト
- **基本設定エリア**：氏名、対象年月、基本出勤時刻、基本退勤時刻、休憩時間（分）
- **ボタン**：勤務表を作成する／途中保存／提出する／Excel出力
- **保存状態の表示**：「未保存の変更があります」「保存中…」「保存済み 11/3 14:32」「提出済み」「保存できませんでした」
- **勤務表**：1ヶ月分の表。列は 日付・曜日・勤務区分・出勤時刻・退勤時刻・休憩時間・実働時間・備考
- **集計**（表の下）：実働時間の合計、月間勤務日数、有給休暇取得日数（全日◯日・半休◯回）、欠勤日数

### (4) 管理者画面
- 対象年月を選ぶと全社員の一覧を表示：氏名、メールアドレス、状態（未作成／作成中／提出済）、実働時間の合計、勤務日数、有給休暇、欠勤、最終更新、操作
- 操作ボタン：「表示」（下に読み取り専用の勤務表を表示）、「Excel」（その人の分を出力）、「差し戻し」（提出済のときだけ）
- 「全員分をExcel出力」：1ファイルに1人1シートでまとめる
- 計算できない日（赤字の日）がある人には「要確認 ◯件」と表示
